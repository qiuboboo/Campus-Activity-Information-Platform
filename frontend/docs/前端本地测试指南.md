## 二、快速启动

### 2.1 安装依赖

```bash
cd frontend
npm install
```

### 2.2 启动开发服务器

```bash
npm run dev
```

默认监听 `http://localhost:3000`，Vite 会自动热重载。

### 2.3 启动方式对照表

| 场景 | 前端启动 | 后端/模拟服务 | 端口 |
|------|---------|--------------|------|
| **纯前端 Mock** | `npm run dev` | `node mock-server.js` | 前端 3000 → Mock 5000 |
| **后端联调** | `npm run dev` | `docker-compose up -d` | 前端 3000 → 后端 5000 |

> Vite 配置了代理（`vite.config.ts`），`/api` 开头的请求会自动转发到 `http://127.0.0.1:5000`。

## 三、Mock 模式测试

无需启动后端 Docker 容器，使用内置的 Mock 服务器即可独立测试前端功能。

### 3.1 启动 Mock 服务器

在另一个终端中执行：

```bash
cd frontend
node mock-server.js
```

Mock 服务器监听 `http://localhost:5000`。  
若端口被占用，可修改 `mock-server.js` 中的 `PORT` 常量。

### 3.2 Mock 数据说明

Mock 服务器提供以下模拟数据：

| 数据类型 | 数量 | 说明 |
|---------|------|------|
| 用户 | 1 | `admin / admin123456`，角色为 admin |
| 海报 | 6 | 含 published（4 条）、pending_review（1 条）、draft（1 条） |
| 知识节点 | 5 | 含活动、组织、地点等类型 |
| 知识关联 | 3 | 节点间关系 |
| 数据源 | 2 | 学校官网和团委公众号 |
| 审计日志 | 1 | 示例提交审核记录 |

### 3.3 Mock 验证步骤

1. 启动 Mock 服务器后，验证可用：
   ```bash
   curl http://localhost:5000/api/health
   # 应返回 {"status":"ok","database":"ok","service":"campus-activity-backend (mock)",...}
   ```

2. 登录测试：
   ```bash
   curl -X POST http://localhost:5000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"admin123456"}'
   # 应返回包含 token 和 user 的 JSON
   ```

3. 打开前端页面 `http://localhost:3000` 进行交互测试。

## 四、后端联调测试

### 4.1 启动后端服务

```bash
cd backend
docker-compose up -d
```

等待所有容器就绪（约 10–30 秒），验证后端正常运行：

```bash
curl http://localhost:5000/api/health
# 应返回 {"status":"ok","database":"ok",...}
```

### 4.2 获取测试 Token

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123456"}'
```

### 4.3 前后端联调验证

1. 确保后端 Docker 容器运行中
2. 启动前端：`npm run dev`（终端不要同时运行 Mock 服务器，避免端口冲突）
3. 访问 `http://localhost:3000`
4. 登录后验证数据是否来自真实后端

## 七、常见问题

### 7.1 Mock 服务器端口被占用

```bash
# 查找占用 5000 端口的进程
netstat -ano | findstr :5000
# 结束进程（假设 PID 为 12345）
taskkill /PID 12345 /F
# 或修改 mock-server.js 中的 PORT 为其他端口（如 5001），
# 同时修改 vite.config.ts 中的 proxy target
```

### 7.2 后端 Docker 容器无法启动

```bash
# 查看容器日志
cd backend
docker-compose logs -f

# 重启指定服务
docker-compose restart api

# 重建并启动
docker-compose down
docker-compose up -d --build
```

### 7.3 前端页面显示空白/加载失败

1. 打开浏览器开发者工具（F12）→ Console 面板查看错误信息
2. 检查 Network 面板确认 API 请求是否成功
3. 确认后端/Mock 服务器正在运行
4. 尝试清除浏览器缓存和 localStorage

### 7.4 安装依赖失败

```bash
# 删除 node_modules 后重新安装
rm -rf node_modules
npm install

# 如遇网络问题，使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### 7.5 代理不生效

确认 `vite.config.ts` 中的代理配置正确：

```ts
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:5000',  // 确保端口与后端/Mock 一致
      changeOrigin: true,
    },
  },
},
```

修改配置后需重新启动 `npm run dev`。

### 7.6 TypeScript 类型错误

```bash
# 运行类型检查
npx vue-tsc --noEmit

# 构建检查
npm run build
```
