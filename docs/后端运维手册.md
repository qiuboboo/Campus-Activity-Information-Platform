# 后端运维手册

> **适用阶段**：正常运行期  
> **更新日期**：2026-05-20

---

## 1. 系统架构速览

```
nginx (optional) → api:5000 (gunicorn + flask)
                        ├── postgres:5432 (主数据库)
                        ├── redis:6379 (缓存 + Celery Broker)
                        ├── worker (Celery 异步任务)
                        ├── beat (Celery 定时任务)
                        └── copilot-proxy:4141 (AI/Embedding 代理)
```

## 2. 日常启动与停止

```bash
# 启动全部服务
docker-compose up -d

# 查看状态
docker-compose ps

# 查看日志
docker-compose logs -f api          # API 服务
docker-compose logs -f worker       # 异步任务
docker-compose logs -f beat         # 定时任务

# 重启单个服务
docker-compose restart api

# 完全停止
docker-compose down

# 完全停止 + 删除数据卷（会丢失所有数据！）
docker-compose down -v
```

### 已知问题

- **docker-compose v1 `KeyError: ContainerConfig`**：发生在重新创建容器时。解决：
  ```bash
  docker rm -f campus-activity-postgres
  docker-compose up -d
  ```
  数据卷 `postgres-data` 不受影响，数据不丢失。

## 3. 数据库维护

### 3.1 备份

```bash
# 备份全部数据
docker exec campus-activity-postgres pg_dump -U campus campus_activity > backup_$(date +%Y%m%d_%H%M%S).sql

# 只备份 schema（不含数据）
docker exec campus-activity-postgres pg_dump -U campus --schema-only campus_activity > schema.sql
```

### 3.2 恢复

```bash
# 先清空再恢复
cat backup_20260520.sql | docker exec -i campus-activity-postgres psql -U campus campus_activity
```

### 3.3 定期备份建议

添加 cron：
```bash
0 3 * * * cd /path/to/backups && docker exec campus-activity-postgres pg_dump -U campus campus_activity > backup_$(date +\%Y\%m\%d).sql && find . -name '*.sql' -mtime +30 -delete
```

### 3.4 PostgreSQL collation 版本更新

如果日志中出现 collation version mismatch 警告：
```bash
docker exec -it campus-activity-postgres psql -U campus -d campus_activity -c "ALTER DATABASE campus_activity REFRESH COLLATION VERSION;"
```

## 4. 常见运维操作

### 4.1 查看 Celery 任务状态

```bash
# 通过 API
curl http://localhost:5000/api/tasks/<task_id>

# 通过 Celery 命令行
docker exec campus-activity-worker celery -A app.celery_app inspect active
docker exec campus-activity-worker celery -A app.celery_app inspect reserved
```

### 4.2 手动触发爬虫

```bash
# 同步模式（等待执行完成）
curl -X POST http://localhost:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"sync": true}'

# 异步模式（返回 task_id，通过 /api/tasks/{id} 查询结果）
curl -X POST http://localhost:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer <admin-token>"
```

### 4.3 查看数据源

```bash
# 列出所有数据源
curl http://localhost:5000/api/data-sources \
  -H "Authorization: Bearer <admin-token>"

# 查看某个数据源的抓取日志
curl http://localhost:5000/api/data-sources/1/logs \
  -H "Authorization: Bearer <admin-token>"
```

```bash
    "source_level": "official",

  }'
```

### 4.5 重建知识图谱

```bash
# 重建所有海报的知识节点
curl -X POST http://localhost:5000/api/knowledge/rebuild \
  -H "Authorization: Bearer <admin-token>"

# 重建单张海报
curl -X POST http://localhost:5000/api/posters/<id>/rebuild-knowledge \
  -H "Authorization: Bearer <admin-token>"
```

### 4.6 重建向量 Embedding

```bash
# 重建所有 Embedding（异步任务）
curl -X POST http://localhost:5000/api/knowledge/rebuild \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"rebuild_embeddings": true}'
```

### 4.7 AI 辅助增强

```bash
# 对海报执行 AI 提取（标题/时间/地点/标签）
curl -X POST http://localhost:5000/api/posters/<id>/ai-enrich \
  -H "Authorization: Bearer <admin-token>"
```

### 4.8 植入演示数据

```bash

```

## 6. 扩展与升级

### 6.1 数据库 Schema 变更

目前使用 `AUTO_CREATE_TABLES=true` + `db.create_all()` 自动建表，适合开发/演示。

**生产环境建议改为 Alembic 迁移流程**：
```bash
# 初始化
flask db init

# 生成迁移脚本
flask db migrate -m "描述变更"

# 执行迁移
flask db upgrade
```

### 6.2 添加新 API

1. 在 `backend/app/api/` 下创建新蓝图文件
2. 在 `backend/app/__init__.py` 中注册蓝图
3. 更新 `docs/backend/` 下对应模块的文档

### 6.3 添加新服务

1. 在 `backend/app/services/` 下创建新服务模块
2. 在 `backend/app/tasks/` 下添加对应的异步任务（如需）

## 7. 故障排查

| 症状 | 可能原因 | 解决 |
|------|---------|------|
| API 返回 502 | gunicorn worker 崩溃 | `docker-compose restart api` |
| 数据库连接失败 | PostgreSQL 未就绪 | 等待 5 秒后重试，或 `docker-compose restart postgres` |
| Embedding 返回 400 | Copilot Proxy 异常 | 检查 `docker-compose logs copilot-proxy` |
| Celery 任务不执行 | Redis 不可达 | 检查 `redis-cli ping` |
| 搜索无向量结果 | Embedding 未构建 | `POST /api/knowledge/rebuild` 加 `rebuild_embeddings: true` |
| 容器重启后数据丢失 | 数据卷未正确挂载 | 检查 `docker-compose.yml` 中 volume 配置 |
