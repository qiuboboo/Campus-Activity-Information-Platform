# 注册页面设计思路

本文件为注册页的设计思路与 TODO 列表，供前端实现与 UI 参考。

## 目标
- 流畅且安全的注册流程，支持邮箱验证码注册
- 提示清晰的密码强度与确认机制
- 响应式与可访问性优先，合规地展示隐私与用户协议

## 页面结构
- 顶部：品牌 logo + 返回首页
- 主体（卡片）
  - 字段：姓名（可选）、邮箱、密码、确认密码、验证码（邮箱）
  - 隐私与条款复选框（必须勾选）
  - 注册按钮（主色）
  - 辅助：已有账号？前往登录

## 交互与验证
- 实时密码强度提示（可使用 zxcvbn 或规则）
- 密码与确认密码实时比对提示
- 获取验证码后按钮倒计时与前端节流（防滥用）
- 注册成功后可自动登录并跳转欢迎页或 `dashboard`

## 隐私与合规
- 明确提供《隐私政策》《用户协议》链接
- 若收集学号等敏感信息，明确用途并考虑放在后续资料页

## 前端验证规则
- 邮箱：格式校验与后端重复性检查
- 密码：最小 8 位，包含大小写字母与数字（显示强度）
- 验证码：6 位数字

## 测试点
- 提交失败（邮箱已注册/验证码错误）的 UI 处理
- 注册成功后的 token 存储与跳转
- 密码强度与确认密码提示在各种输入场景的表现

## API 参考（前端示例）
- 发送验证码：POST `/api/auth/send-code` { email }
- 注册：POST `/api/auth/register` { username, email, password, code }

## 实现约定

- 页面实现采用单文件组件（Single File Component）：每个页面以一个完整的 `.vue` 文件实现，包含模板、脚本与样式，便于页面级别维护与路由管理。
- 仅在确有复用价值或组件复杂度较高时，将部分 UI/逻辑拆出到 `frontend/src/components` 中作为子组件；否则保留在单文件内以降低项目文件数量和认知成本。
