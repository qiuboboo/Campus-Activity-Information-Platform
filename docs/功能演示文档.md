创建一个指向中山大学计算机学院学术活动页面的数据源，配置 CSS 选择器来提取活动列表和详情内容。

curl -X POST http://127.0.0.1:5000/api/data-sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "中山大学计算机学院学术活动",
    "base_url": "https://cse.sysu.edu.cn/research/activity",
    "list_selector": ".eventitems a[href^=\"/event/\"]",

## 4. 网页爬虫抓取

### 4.1 异步抓取（默认）

提交异步抓取任务，立即返回 task_id，任务在后台执行。

```bash
curl -X POST http://127.0.0.1:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}'
```

预期输出（202 Accepted）：
```json
{
  "task_id": "246a8b1e-3c7f-4a12-9d8f-1e2f3a4b5c6d",
  "status_url": "/api/tasks/246a8b1e-3c7f-4a12-9d8f-1e2f3a4b5c6d"
}
```

### 4.2 查询异步任务状态

```bash
curl http://127.0.0.1:5000/api/tasks/246a8b1e-3c7f-4a12-9d8f-1e2f3a4b5c6d \
  -H "Authorization: Bearer $TOKEN"
```

任务执行中：
```json
{
  "task_id": "246a8b1e-3c7f-4a12-9d8f-1e2f3a4b5c6d",
  "state": "STARTED"
}
```

任务完成：
```json
{
  "task_id": "246a8b1e-3c7f-4a12-9d8f-1e2f3a4b5c6d",
  "state": "SUCCESS",
  "result": {
    "success": true,
    "posters_created": 12,
    "duplicates_skipped": 0,
    "average_quality_score": 100.0,
    "pages_found": 12,
    "pages_succeeded": 12,
    "pages_failed": 0

```

### 4.3 同步抓取（调试模式）

添加 `{"sync": true}` 参数，请求会阻塞直到抓取完成，适合调试。

```bash
curl -X POST http://127.0.0.1:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sync": true}'
```

### 4.4 查看抓取日志

```bash
curl http://127.0.0.1:5000/api/data-sources/1/logs \
  -H "Authorization: Bearer $TOKEN"
```

- 抓取时间、状态、页面数量
- 去重数量（`duplicates_skipped`）
- 新建草稿数量（`drafts_created`）
- 平均质量分数（`average_quality_score`）

## 6. 活动治理——质量评分

爬虫创建草稿时自动执行质量评分。评分规则如下：

| 规则 | 扣分/加分 |
|------|-----------|
| 标题为空 | -30 |
| 标题过短（<5 字符） | -15 |
| 摘要为空 | -15 |
| 缺少活动时间 | -15 |
| 缺少活动地点 | -10 |
| 缺少来源链接 | -10 |
| 正文过短（<50 字符） | -10 |
| 正文偏短（50-200 字符） | -5 |
| 疑似重复 | -20 |
| 官方来源 | +10 |

分数范围：0-100，爬虫日志记录每次抓取的平均质量分数。

### 验证质量评分

查看爬虫创建的海报，`quality_score` 和 `quality_notes` 字段反映评分结果：

```bash
curl "http://127.0.0.1:5000/api/posters?status=draft&per_page=3" \
  -H "Authorization: Bearer $TOKEN" \
  | python3 -c "
import sys,json
data = json.load(sys.stdin)
for p in data['items']:
    print(f'#{p[\"id\"]} score={p[\"quality_score\"]} notes={p[\"quality_notes\"]}')
"
```

预期输出示例：
```
#4 score=100 notes=官方来源加分
#5 score=100 notes=官方来源加分
#6 score=100 notes=官方来源加分
```

## 7. 活动治理——审核队列

审核队列提供活动治理的集中管理入口，支持多种过滤和排序方式。

### 7.1 查看所有待审核草稿

```bash
curl "http://127.0.0.1:5000/api/posters/review-queue?status=draft" \
  -H "Authorization: Bearer $TOKEN"
```

返回包含质量评分和去重信息的完整海报列表。

### 7.2 按来源类型过滤

```bash
# 只查看爬虫导入的草稿
curl "http://127.0.0.1:5000/api/posters/review-queue?status=draft&source_type=crawl" \
  -H "Authorization: Bearer $TOKEN"

# 只查看手动创建的草稿
curl "http://127.0.0.1:5000/api/posters/review-queue?status=draft&source_type=manual" \
  -H "Authorization: Bearer $TOKEN"
```

### 7.3 按去重分组过滤

```bash
curl "http://127.0.0.1:5000/api/posters/review-queue?duplicate_group_key=xxx" \
  -H "Authorization: Bearer $TOKEN"
```

### 7.4 按质量分数排序

```bash
# 质量从高到低
curl "http://127.0.0.1:5000/api/posters/review-queue?sort_by=-quality_score" \
  -H "Authorization: Bearer $TOKEN"

# 质量从低到高（优先处理低质量草稿）
curl "http://127.0.0.1:5000/api/posters/review-queue?sort_by=quality_score" \
  -H "Authorization: Bearer $TOKEN"
```

### 7.5 分页

```bash
curl "http://127.0.0.1:5000/api/posters/review-queue?page=1&per_page=5" \
  -H "Authorization: Bearer $TOKEN"
```

## 9. 活动治理——重复检测

### 9.1 验证去重效果

首次抓取时创建 12 条草稿，再次抓取同一数据源时会检测到重复：

```bash
# 第一次抓取（创建 12 条草稿）
curl -X POST http://127.0.0.1:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sync": true}'
```
输出：`"posters_created": 12, "duplicates_skipped": 0`

```bash
# 第二次抓取（全部为重复）
curl -X POST http://127.0.0.1:5000/api/data-sources/1/crawl \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sync": true}'
```
输出：`"posters_created": 0, "duplicates_skipped": 12`

### 9.2 查询海报的重复项

```bash
# 查看海报 4 的重复信息
curl http://127.0.0.1:5000/api/posters/4/duplicates \
  -H "Authorization: Bearer $TOKEN"
```

返回 `duplicate_group_key` 和 `source_fingerprint` 匹配的重复海报列表。

### 9.3 来源合并

将一条海报合并到另一条，被合并的海报会被删除，其来源 URL 记录到主海报的审计日志中。

```bash
curl -X POST http://127.0.0.1:5000/api/posters/4/merge-source \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_poster_id": 5}'
```
