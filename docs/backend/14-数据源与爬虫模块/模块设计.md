## 安全约束

### URL 与请求安全

**URL 白名单机制**
- 每个数据源必须配置 `allowed_domains`（允许抓取的域名列表）
- 爬虫启动时检查目标 URL 的域名是否在 `allowed_domains` 中
- 域名匹配采用精确匹配或后缀匹配（如 `*.sysu.edu.cn`）
- 不允许单个 IP、localhost、127.0.0.1、内网地址段作为爬虫目标

```python
_ALLOWED_SCHEMES = ("http", "https")
_BLOCKED_HOSTS = (
    "localhost", "127.0.0.1", "0.0.0.0",
    "10.", "172.16.", "172.17.", "172.18.", "172.19.",
    "172.20.", "172.21.", "172.22.", "172.23.", "172.24.",
    "172.25.", "172.26.", "172.27.", "172.28.", "172.29.",
    "172.30.", "172.31.", "192.168.",
)

def validate_target_url(url: str, allowed_domains: list[str]) -> None:
    """验证目标 URL 是否允许被抓取。"""
    parsed = urllib.parse.urlparse(url)
    if parsed.scheme not in _ALLOWED_SCHEMES:
        raise SecurityError(f"不支持的 URL 协议: {parsed.scheme}")
    host = parsed.hostname or ""
    if any(host.startswith(prefix) for prefix in _BLOCKED_HOSTS):
        raise SecurityError(f"禁止访问内网地址: {host}")
    if not any(host.endswith(domain) for domain in allowed_domains):
        raise SecurityError(f"域名不在白名单中: {host}")
```

**请求约束**
- 只允许 GET 请求
- 不允许自定义 Cookie、Authorization 等敏感字段
- 不允许跟随重定向到外部域名
- 不允许使用 HTTP 基本认证、客户端证书
- 不允许访问 FTP、file、data 等非 HTTP 协议

```python
def _fetch(url: str, allowed_domains: list[str]) -> str:
    validate_target_url(url, allowed_domains)
    resp = requests.get(url, timeout=_REQUEST_TIMEOUT,
                        headers={"User-Agent": _USER_AGENT},
                        stream=True, allow_redirects=True)
    if resp.history:
        final_url = resp.url
        validate_target_url(final_url, allowed_domains)
    return _read_response(resp)
```

### 频率与资源控制

**请求限速**：每个数据源配置 `request_interval` 参数，默认 2 秒

**并发控制**：单次爬虫任务串行执行，不同数据源共享 Celery Worker 并发限制

**数据量控制**：
| 限制项 | 上限 |
|--------|------|
| 单次请求最大响应体 | 2 MB |
| 单次任务最大页面数 | 50 页 |
| 单次任务总执行时间 | 30 分钟 |
| 单条标题最大长度 | 200 字符 |
| 单条摘要最大长度 | 500 字符 |

### 内容安全

**XSS 防护**：爬取到的原始文本必须经过 HTML 标签剥离，只保留纯文本

**敏感信息过滤**：对爬取内容做手机号、身份证号、银行卡号等关键词过滤和自动掩码

```python
_SENSITIVE_PATTERNS = {
    "phone": re.compile(r"1[3-9]\d{9}"),
    "id_card": re.compile(r"\d{17}[\dXx]"),
    "email": re.compile(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b"),
}

def mask_sensitive(text: str) -> str:
    for name, pattern in _SENSITIVE_PATTERNS.items():
        text = pattern.sub(lambda m: m.group()[:3] + "****" + m.group()[-2:], text)
    return text
```

### 审计与监控

- 每次爬虫请求记录：时间、目标 URL、数据源 ID、状态码、响应大小
- 每次安全拦截记录：时间、目标 URL、拦截原因
- 安全事件日志独立存储
- 同一数据源连续 3 次安全拦截时，自动禁用该数据源

### 安全配置默认值

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `allowed_domains` | `[]`（必须手动配置） | 域名白名单 |
| `request_interval` | 2 秒 | 请求间隔 |
| `max_pages_per_crawl` | 50 | 单次任务最大页面数 |
| `max_response_bytes` | `2 * 1024 * 1024` | 单次响应最大字节数 |
| `crawl_soft_timeout` | 1800 秒 | 单次任务软超时 |
| `block_internal_ips` | `true` | 是否禁止内网地址 |
| `allowed_schemes` | http, https | 允许的协议 |

## 微信文章抓取方案

### 方案一：搜狗微信搜索（已实现）

通过 `weixin.sogou.com` 搜索关键词，获取文章标题、发布时间和搜狗跳转链接。支持多页搜索、精确匹配、反爬检测。

**已知限制：**
- `resolve_real_url()` 通过 `SOGOU_COOKIES` 环境变量注入浏览器 Cookie 可绕过反爬
- `mp.weixin.qq.com` 正文页面受微信风控，纯 HTTP 请求无法拿到正文
- 搜索结果不限定于某个公众号，而是关键词全匹配

**当前策略**：搜狗搜索 → 标题 + 时间 + 真实 URL → `auto_extract_fields` 提取活动信息 → 创建 Poster 草稿（正文留空，URL 可供跳转阅读）

### 方案二：微信公众平台后台 API（备选）

扫码登录 `mp.weixin.qq.com` → 获取 Cookie → 搜索目标公众号 → 通过 fakeid 获取文章列表 → Cloudflare Worker 代理抓正文

**优势**：直接获取真实文章 URL、可限定公众号、可拿到全文
**风险**：需微信公众号、每 4 天扫码续期、有频率限制、存在账号功能限制风险
