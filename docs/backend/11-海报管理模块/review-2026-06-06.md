## 发现的问题

### 1. ai-enrich 缺少 `get_or_404` 检查

**文件**: `app/api/posters.py:389`

`ai_enrich()` 未调用 `Poster.query.get_or_404(poster_id)`，依赖 `enrich_poster()` 内部返回 None 来区分"海报不存在"和"LLM 不可用"——两者都返回 400，无法区分。建议在函数开头加上：
```python
poster = Poster.query.get_or_404(poster_id)
```

（低优先级，不影响功能正确性）

### 2. 模块设计文档缺状态机图

文档描述"草稿→提交审核→审核通过/驳回"流程，但没有可视化状态机图。API接口.md 有文本版流转线，可以搬到模块设计.md。

### 3. 测试文档需更新

测试.md 列出了 9 个测试类（review前），新增的 TestDuplicates / TestRebuildKnowledge / TestAiEnrich 三个类未列入，需补充。
