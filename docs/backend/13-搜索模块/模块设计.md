# 搜索模块设计

## 功能职责

- 提供内部知识库检索
- 提供外部扩展搜索
- 统一返回可用于展示和入库的搜索结果

## 搜索结构

1. **内部搜索**：在平台已有海报和知识节点中检索，优先采用语义向量检索，可辅以 PostgreSQL 全文检索作为补充。
2. **外部搜索**：通过多引擎搜索服务（SearXNG 聚合 Google、Bing、DuckDuckGo、百度 + 搜狗微信搜索），从校内官网、院系页面、专题页、社交媒体等外部来源获取信息。支持 LLM 兜底。

## 检索策略

- 内部搜索面向平台内已有知识的快速定位，支持全文 LIKE 检索和语义向量检索（`EMBEDDING_ENABLED=true` 时启用）
- 语义向量检索使用 Copilot Pro 代理的 `text-embedding-3-small` 模型将查询转为 1536 维向量，计算余弦相似度排序
- 向量检索结果与全文检索结果合并返回，确保即使向量检索无结果时仍有 LIKE 兜底
- 外部搜索面向平台外新增信息的发现、验证和草稿补全
- 当前版本建议将内部搜索与外部搜索分开展示，避免结果语义混淆

## 排序参数

内部搜索支持以下排序方式：
- `relevance`：相关性（向量评分或创建时间）
- `created_at`：按创建时间
- `title`：按标题
- `event_time`：按活动时间

支持 `asc` / `desc` 排序方向。
