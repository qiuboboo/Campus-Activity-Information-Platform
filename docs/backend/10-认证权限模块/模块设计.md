# 认证与权限模块设计

## 功能职责

- 用户注册与登录
- JWT 签发与校验
- 基于角色的访问控制

## 历史改进

- **已实现**：图形验证码已集成到登录和注册接口（`GET /api/auth/captcha` 获取验证码，提交时携带 `captcha_token` + `captcha_code`）。
- **已实现**：邮箱验证码注册流程（`POST /api/auth/send-code` 发送 6 位验证码到邮箱，注册时需携带 `email` + `verification_code` + `captcha`）。
- **已实现**：登录支持邮箱地址（与用户名二选一）。

## 角色定义

| 角色 | 权限 |
| --- | --- |
| `viewer` | 查看活动、搜索、浏览关联信息 |
| `publisher` | 创建和编辑海报草稿，提交发布审核 |
| `admin` | 管理数据源、用户、抓取任务和审核发布 |

## 实现方式

- 在 Flask 中使用 `auth` 蓝图统一处理登录和鉴权
- 登录成功后返回 Access Token
- 通过装饰器实现接口级权限控制
