# 订阅通知与个人日历模块设计

## 订阅与通知

### 设计思路

用户不需要每天主动打开平台查看活动。通过订阅机制，当用户关心的新活动发布时，平台主动触达用户，将"人找活动"变为"活动找人"。

### 功能职责

- 用户可订阅知识节点（地点、主办方、活动类型、主题）
- 用户可订阅关键词（如"讲座"、"竞赛"）
- 新海报发布上线时，自动匹配订阅并产生通知
- 提供通知列表查看和已读标记

### 处理流程

```text
海报审核通过 → 提取关联知识节点 → 匹配 subscriptions 表
    → 找到所有订阅了这些节点的用户 → 创建 notification 记录
    → （可选）调用推送通道（邮件/企业微信等）
```

### 适用场景

- 学生订阅"大礼堂"地点，每次该地点有活动自动收到通知
- 学生订阅"讲座"类型，不再错过感兴趣的学术活动
- 管理员订阅"待审核"事件，新草稿提交时收到提醒

## 个人日历

### 设计思路

将平台从"活动公告板"升级为"个人日程工具"。用户通过一键导入 .ics 文件，将活动添加到手机/电脑日历，每次规划时间都会看到平台活动。

### 功能职责

- 为单张海报生成标准 .ics 日历文件下载
- 记录用户"已添加日历"的活动列表（user_calendar_events）
- 提供"我的日历"视图，按时间线展示用户收藏的所有活动
