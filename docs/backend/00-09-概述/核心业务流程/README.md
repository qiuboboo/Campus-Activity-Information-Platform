# 核心业务流程

## 1. 海报发布流程

```text
用户提交文本
-> 后端提取结构化字段
-> 生成 HTML 海报
-> 存库为草稿
-> 用户提交审核
-> 管理员审核内容
-> 审核通过后，匹配知识节点
-> 建立海报关联
-> 发布上线
-> 可选异步生成向量
-> 推送通知：匹配订阅用户 → 创建通知记录
```

海报发布上线后，自动进入订阅匹配流程：

1. 收集该海报关联的所有知识节点（地点、主办方、主题等）
2. 在 `subscriptions` 表中查找订阅了这些节点的用户
3. 同时查找订阅了该海报标题/类型中关键词的用户
4. 为每个匹配用户创建一条 `notification` 记录
5. （可选）通过邮件或推送通道发送通知

## 2. 爬虫入库流程

```text
管理员配置数据源
-> Celery 触发抓取任务
-> 抽取网页标题与正文
-> 生成海报草稿
-> 生成来源节点和关联信息
-> 写入抓取日志
```

## 3. 搜索流程

```text
用户输入查询
-> 若选择内部搜索，则在海报与知识节点中执行向量检索或全文检索
-> 若选择外部搜索，则调用多引擎搜索服务（SearXNG + 搜狗），可选 LLM 兜底
-> 返回按来源区分的结果
```

参见 [搜索模块](13-搜索模块/模块设计.md) 和 [搜索接口契约](13-搜索模块/接口契约.md)。
