# 规模、容量与预算估算

> 基于 2026 年 4 月 28 日的课程项目阶段假设，面向"校内官方较大型活动展示平台"的第一版实现。

## 1. 活动规模估算

| 项目 | 估算范围 |
| --- | --- |
| 年活动总数 | 150-300 条 |
| 月均活动数 | 12-25 条 |
| 高峰月活动数 | 25-40 条 |
| 单张海报直接知识节点数 | 6-8 个 |
| 唯一知识节点总数 | 200-350 个/年 |

## 2. 关系数量估算

- `poster_node`：约 900-2400 条/年
- `poster_links`：约 300-1200 条/年

## 3. 数据库存储空间估算

| 项目 | 估算范围 |
| --- | --- |
| 海报主数据 | 6-18 MB/年 |
| 知识节点与关系表 | 5-20 MB/年 |
| Embedding 向量 | <10 MB/年 |
| 抓取日志 | 50-200 MB/年 |
| 含索引、WAL、备份后的数据库总占用 | 0.3-1 GB/年 |

若后续额外保存网页快照、截图、原图附件等非结构化资源，媒体与附件存储约 1-5 GB/年。

## 4. 服务器配置建议

| 场景 | 建议配置 | 说明 |
| --- | --- | --- |
| 课程演示版 | 2核4G + 50GB | 适合低并发、单机部署、AI 走外部 API |
| 试运行版 | 4核8G + 70GB | 更适合同机运行 Web、Worker、数据库、缓存 |

## 5. 云服务器预算估算

| 配置 | 年预算参考 |
| --- | --- |
| 2核4G + 50GB | 约 68-562 元/年 |
| 4核8G + 70GB | 约 1123 元/年 |

## 6. 数据库与缓存预算

第一版不单独购买托管数据库，与应用服务同机部署，0 元额外授权费。

## 7. AI API 成本估算

采用"AI 增强 + 非 AI 兜底"的轻量策略：

1. **活动文本抽取**：300 条/年，轻量模型下数美元/年
2. **外部搜索摘要**：月均 300 次，低成本模型下十美元级别/年
3. **Embedding**：活动总量小，可忽略不计

## 8. 推荐总预算

| 方案 | 预算参考 |
| --- | --- |
| 课程项目版 | 数百元/年 + 少量美元级 API 成本 |
| 校内试运行版 | 约 1000 元/年 + 十几到几十美元级 API 成本 |
