| 文件 | 类型 | 路径 |

```bash
cd backend && python -m pytest tests/test_knowledge_service.py -v

# 运行单个测试类
cd backend && python -m pytest tests/test_knowledge_service.py::TestTopicFromPoster -v
```

## 测试配置与固件

### 应用配置

见 `conftest.py` 中 `TestConfig`，使用 SQLite 内存数据库，禁用 Redis 和 Embedding。

### 共享固件

| 固件 | 定义位置 | 说明 |
|------|----------|------|
| `app` | conftest.py | 创建应用、推上下文、建表、预置 admin 用户 |
| `client` | conftest.py | Flask 测试客户端 |
| `admin_headers` | conftest.py | admin 角色的 JWT 认证头 |
| `publisher_headers` | conftest.py | publisher 角色的 JWT 认证头 |
| `sample_published_poster` | conftest.py | 已发布的海报（含知识节点），用于关联测试 |

### 单元测试上下文管理

服务层单元测试（如 `TestRebuildPosterNodes`）需要应用上下文，通过 `app` 固件的 `with app.app_context():` 包裹数据库操作。

### 数据隔离

每个测试方法运行在独立的数据库中。服务层测试手动创建模型对象并调用 `db.session.flush()` 或 `db.session.commit()` 来持久化。

## 知识节点生成规则

测试中验证了以下知识节点提取规则：

### 关系类型映射

| 节点类型 | 关系类型 | 数据来源 |
|----------|----------|----------|
| `time` | `has_time` | `poster.event_time` → 转为日期字符串 |
| `place` | `has_place` | `poster.location` → 经字典标准化 |
| `organization` | `has_org` | `poster.organizer` → 经字典标准化 |
| `topic` | `has_topic` | 从 title + summary 关键词匹配 |
| `source` | `has_source` | `poster.source_url` |

### 海报间关系规则

| 链接类型 | 规则字段 | 条件 |
|----------|----------|------|
| `same_day` | `event_date` | 两张海报的 event_time 日期相同 |
| `same_place` | `location` | 两张海报的 location 相同 |
| `same_org` | `organizer` | 两张海报的 organizer 相同 |
| `same_topic` | `topic` | 两张海报的 topic 关键词提取结果相同 |

### 字典标准化

服务层通过 `dict_manager.normalize()` 对 location 和 organizer 进行受控词表规范化。单元测试中未直接测试字典模块，但 `_node_specs_for_poster` 的集成测试覆盖了这一调用路径（异常被捕获并忽略，测试使用简单值）。

## 关键测试场景说明

### 关键词主题检测

`_topic_from_poster()` 使用包含 9 组关键词-主题映射的规则表。测试覆盖了：
- 科技 → 科技活动
- 讲座 → 讲座
- 竞赛/比赛 → 竞赛
- 招聘 → 招聘
- 无匹配 → None

### 重复节点去重

`get_or_create_node()` 通过 `(name, node_type)` 唯一约束查找已有节点，重复调用返回同一实例。数据库层面有 `uq_knowledge_nodes_name_type` 唯一索引保障。

### 完整知识重建流程

`TestRebuildPosterKnowledge.test_full_rebuild_creates_nodes_and_links` 模拟了两张同日期（2026-05-10）、同地点（大礼堂）、同主办方（校团委）的海报，验证：
1. `nodes` 列表非空（至少包含 time、place、org、topic 节点）
2. `links` 列表非空（至少存在 same_day、same_place、same_org 三种链接）
