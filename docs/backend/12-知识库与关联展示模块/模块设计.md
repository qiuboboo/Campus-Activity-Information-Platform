# 知识库与关联展示模块设计

## 功能职责

- 管理平台中的知识节点信息
- 为活动提供结构化关联对象
- 支持海报中心式关联图展示
- 展示当前海报的直接关联知识节点
- 展示与这些节点相关的其他海报
- 展示海报之间的关联原因与官方来源

## 知识节点类型

- **时间节点**：日期、时间段、学期阶段
- **地点节点**：校区、建筑、会场
- **组织节点**：学校、学院、部门、主办单位
- **主题节点**：讲座、晚会、竞赛、论坛
- **对象节点**：面向人群、报名对象
- **来源节点**：官网栏目、通知页面、专题页

## 知识节点生成机制

采用"类型预定义 + 字典标准化 + 规则抽取 + AI 增强"的组合方式：

1. **类型预定义**：系统设计阶段人工定义知识节点类型（时间、地点、组织、主题等）
2. **实例抽取**：运行时从海报文本、抓取网页、录入表单中提取具体节点实例
3. **字典标准化**：对高频字段维护小型受控词表和别名表，统一名称
4. **规则建边**：海报与节点间的关系优先依据共享节点和明确规则生成
5. **AI 增强**：对复杂文本使用大模型补充识别

## 字典与规则

维护少量稳定的受控词表：
- 地点字典：校区、楼宇、礼堂、报告厅等
- 组织字典：学校部门、学院、官方组织等
- 主题标签表：科技节、招聘会、讲座等
- 来源字典：学校官网、学院官网等

作用：统一命名、处理别名、提高抽取准确率、为关系生成提供稳定节点。

## 关系知识点选取

优先使用以下知识点建立关系：
- 时间、地点、主办方、活动主题、来源

## 关系生成规则

- 同日期 → `same_day`
- 同地点 → `same_place`
- 同主办方 → `same_org`
- 同主题标签 → `same_topic`

## 设计原则

- 采用"海报为中心、周围知识节点辐射展开"的结构
- 一张海报连接多个知识节点
- 海报之间可建立关系（同时间、同地点、同主办方、同主题）
- 提供两层可点击的扩展链接
- 当前版本以官方活动为主，默认来源可信

## 两级超链接模型

1. **一级关联**：海报直接连接时间、地点、主办方、主题、来源等知识节点
2. **二级扩展**：点击知识节点后进入详情页，查看该节点的扩展信息和关联海报

### 示例

以"2026 校园科技文化节开幕式"海报为例：

- 一级关联节点：时间 `2026-05-10 19:00`、地点 `大学生活动中心大礼堂`、主办方 `校团委`、类型 `开幕式`、来源 `学校官网通知`
- 二级扩展：点击地点可查看该地点详情和其他活动，点击主办方可查看历史活动等

## 关联信息展示

### 关联逻辑

- **一级关联**：当前海报直接连接的知识节点
- **二级关联**：与这些知识节点共享关系的其他海报
- **海报间关系**：按时间、地点、主办方、主题等维度建立链接

### 设计目标

本模块是"可解释的官方活动关联展示系统"，重点强调：
- 为什么相关
- 信息来自哪里
- 关联路径是什么

### 图结构

采用两类边：
- **海报→知识节点**：如"活动 A → 地点:大学生活动中心"
- **海报→海报**：如"活动 A → 活动 B"，关系类型为"同日举办""同地点举办"等
